# gma.math.prepro.fill_nodata


<span style="background-color:#EFF0FC;display: block;line-height:1.5"><span style="color: gray;font-size:90%;">function</span> <span style="color: #616AE5; font-weight: bold;font-size: 150%;">fill_nodata</span><span style="font-style: italic; color: black;font-size: 130%;">(data, nodatas = <span style="color:#48566B">None</span>, method = <span style="color:#48566B">"linear"</span>, axis = <span style="color:#48566B">None</span>, **kwargs):</span></span>

Interpolate missing or abnormal values.

<p style="background-color:none;font-size: 120%;display: block;color:#9298ED; font-weight: bold;">Parameters:</p><p style="text-indent: 1em;"><b>data: </b> <code>list||tuple||Series||DataFrame||array</code>.</p><p style="padding-left: 1em;text-indent: 1em;">    Data to be filled.</p><p style="background-color:none;font-size: 120%;display: block;color:#9298ED; font-weight: bold;">Optional:</p><p style="text-indent: 1em;"><b>nodatas  = </b> <code>float||list</code>. <span style="color:#48566B;">Default None.</span></p><p style="padding-left: 1em;text-indent: 1em;">Flags missing values that need to be filled. Can be a number (float) or a list of numbers (list).</p><p style="padding-left: 1em;text-indent: 1em;">Note: 1. When nodatas is a list, all values in the list will be interpolated.</p><p style="padding-left: 1em;text-indent: 1em;">2. The original NAN, INF, strings that cannot be converted into numbers and other abnormal values in the data will also be interpolated.</p><p style="text-indent: 1em;"><b>method  = </b> <code>str</code>. <span style="color:#48566B;">Default 'linear'.</span></p><p style="padding-left: 1em;text-indent: 1em;">Interpolation method. Supported methods include: 'index', 'values', 'pad', 'nearest', 'zero', 'slinear', 'quadratic', 'cubic', 'spline', 'barycentric', 'polynomial', 'from_derivatives', 'krogh', 'piecewise_polynomial','pchip', 'akima', 'cubicspline', 'linear'.</p><p style="text-indent: 1em;"><b>axis  = </b> <code>int</code>. <span style="color:#48566B;">Default None.</span></p><p style="padding-left: 1em;text-indent: 1em;">Axis used for data interpolation. By default (None), if the data is less than 3 dimensions, the first dimension is the axis; if the data is higher than 3 dimensions, the penultimate dimension is the axis.</p><p style="text-indent: 1em;"><b>**kwargs. Additional arguments to pass to the interpolation function.</b>.</p><p style="padding-left: 1em;text-indent: 1em;">    For example: method is 'polynomial' or 'spline', you need to set order (order), the default order is 3.</p><p style="background-color:none;font-size: 120%;display: block;color:#9298ED; font-weight: bold;">Returns:</p><p style="text-indent: 1em;"><b>Type: </b> <code>Series||DataFramereturnstheinputtype;list||tuple||arrayreturnsanarray</code>.</p>
