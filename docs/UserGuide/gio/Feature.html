Luo_Suppe2026-08-15

gma.gio.Feature

[class] Feature(geom = None, values = [], gtype = None, ftypes = None, crs = None):

Create a Feature object.

Optional:

geom = None||Geometry. Default None.

The geometry of the feature. If None, create an empty geometry.

values = list. Default [].

The field values of the feature.

gtype = str||None. Default None.

The geometry type of the feature. See `dtypes.DefinedGeomTypes` for valid types. If None, use the geometry type of `geom`.

ftypes = None||list of FieldType. Default None.

The FieldTypes of the feature. If None, create an empty FieldTypes.

crs = str||int||None. Default None.

The projection of the geometry. If None, no projection is set.

Example

from gma import gio

ly = gio.open_vector('Australia.shp')
ft = ly.get_feature(0)                          # Western Australia

print('fid     :', ft.fid)
print('name    :', ft.fields['name'])
print('geometry:', ft.geom.gtype)

# Build a new Feature from the geometry and fields of an existing one
new_ft = gio.Feature(geom=ft.geom, values=list(ft.fields.values()), ftypes=ft.ftypes)
print('new ft  :', new_ft.fid, new_ft.fields['name'], repr(new_ft.crs))

fid     : 0
name    : Western Australia
geometry: MultiPolygon
new ft  : -1 Western Australia <CoordinateReferenceSystem:WGS 84>

set_geom(geom)

Set feature geometry. This function updates the features geometry, except that this function does not assume ownership of the passed geometry, but instead makes a copy of it.

Parameters:

geom: Geometry.

new geometry to apply to feature.

Returns:

Type: None.

Replace the geometry in place; field values are unchanged.

Example:

from gma import gio

ly = gio.open_vector('Australia.shp')
ft = ly.get_feature(0)                  # Western Australia
new_geom = ly.get_feature(1).geom       # Northern Territory

print('Before:', ft.fields['name'], tuple(round(v, 2) for v in ft.geom.bounds))
ft.set_geom(new_geom)
print('After :', ft.fields['name'], tuple(round(v, 2) for v in ft.geom.bounds))

Before: Western Australia (112.91, -35.1, 129.0, -13.74)
After : Western Australia (129.0, -26.0, 138.0, -10.97)

update(other)

Set one feature from another. Overwrite the contents of this feature from the geometry and attributes of another.

Parameters:

other: Feature.

feature from which geometry and field values will be copied.

Returns:

Type: None.

Overwrite geometry and field values in place. The fid is not copied (-1).

Example:

from gma import gio

ly = gio.open_vector('Australia.shp')
ft = ly.get_feature(0)                  # Western Australia
other = ly.get_feature(2)               # South Australia

print('Before:', ft.fields['name'], tuple(round(v, 2) for v in ft.geom.bounds))
ft.update(other)
print('After :', ft.fields['name'], tuple(round(v, 2) for v in ft.geom.bounds))
print('fid   :', ft.fid)

Before: Western Australia (112.91, -35.1, 129.0, -13.74)
After : South Australia (129.0, -38.07, 141.03, -26.0)
fid   : -1
