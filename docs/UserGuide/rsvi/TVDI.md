# gma.rsvi.TVDI


<span style="background-color:#EFF0FC;display: block;line-height:1.5"><span style="color: gray;font-size:90%;">function</span> <span style="color: #616AE5; font-weight: bold;font-size: 150%;">TVDI</span><span style="font-style: italic; color: black;font-size: 130%;">(vi, lst, vi_range = <span style="color:#48566B">[0.2, 0.8]</span>, lst_range = <span style="color:#48566B">[200, 350]</span>, delta = <span style="color:#48566B">0.01</span>, vi_nodata = <span style="color:#48566B">None</span>, lst_nodata = <span style="color:#48566B">None</span>, out_nodata = <span style="color:#48566B">-1.0</span>):</span></span>

Calculate the Temperature Vegetation Drought Index.

<p style="background-color:none;font-size: 120%;display: block;color:#9298ED; font-weight: bold;">Parameters:</p><p style="text-indent: 1em;"><b>vi: </b> <code>array</code>.</p><p style="padding-left: 1em;text-indent: 1em;">    Vegetation index data.</p><p style="text-indent: 1em;"><b>lst: </b> <code>array</code>.</p><p style="padding-left: 1em;text-indent: 1em;">    Land surface temperature (K).</p><p style="background-color:none;font-size: 120%;display: block;color:#9298ED; font-weight: bold;">Optional:</p><p style="text-indent: 1em;"><b>vi_range  = </b> <code>list</code>. <span style="color:#48566B;">Default [0.2, 0.8].</span></p><p style="padding-left: 1em;text-indent: 1em;">    Valid value range of vegetation index participating in wet and dry edge fitting.</p><p style="text-indent: 1em;"><b>lst_range  = </b> <code>list</code>. <span style="color:#48566B;">Default [200, 350].</span></p><p style="padding-left: 1em;text-indent: 1em;">    Valid value range of land surface temperature participating in wet and dry edge fitting.</p><p style="text-indent: 1em;"><b>delta  = </b> <code>float</code>. <span style="color:#48566B;">Default 0.01.</span></p><p style="padding-left: 1em;text-indent: 1em;">    The sample spacing for vegetation index sampling during wet and dry edge fitting.</p><p style="text-indent: 1em;"><b>vi_nodata  = </b> <code>float</code>. <span style="color:#48566B;">Default None.</span></p><p style="padding-left: 1em;text-indent: 1em;">    Invalid value in vegetation index data.</p><p style="text-indent: 1em;"><b>lst_nodata  = </b> <code>float</code>. <span style="color:#48566B;">Default None.</span></p><p style="padding-left: 1em;text-indent: 1em;">    Invalid value in land surface temperature data.</p><p style="text-indent: 1em;"><b>out_nodata  = </b> <code>float</code>. <span style="color:#48566B;">Default -1.0.</span></p><p style="padding-left: 1em;text-indent: 1em;">Invalid values in TVDI results.
